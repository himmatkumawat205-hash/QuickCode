# QuickCode

### Share code with anyone using just a 6-character code.

QuickCode is a website that makes sharing code simple. Instead of copying long messages or sending files, share your code through a short, 6-character code that another person can use to access it.

## How It Works

1. **Add your code** — Enter the code you want to share on QuickCode.
2. **Get a sharing code** — Get a 6-character code for your snippet.
3. **Share it** — Send that 6-character code to anyone you want.
4. **Access the code** — The recipient enters the sharing code on QuickCode to view your snippet.

## Why QuickCode?

- **Simple sharing:** Pass along a short code instead of a long snippet.
- **Easy access:** Use the 6-character code to find the shared code.
- **Made for everyday use:** Share examples with classmates, exchange snippets with teammates, or help someone work through a coding problem.

## Example

You want to share this snippet:

```javascript
console.log("Hello from QuickCode!");
```

Add it to QuickCode and get a sharing code, such as `A1B2C3`.

Send `A1B2C3` to a friend. They enter it on QuickCode to access your snippet.
